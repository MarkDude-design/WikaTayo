# Project Ulam / WikaTayo cross-project bridge

Project Ulam is a comedy and interactive exhibit project. WikaTayo is the language-oriented workspace. **Shared surface:** the English / Tagalog / Taglish toggle, which should use distinct natural registers rather than literal one-to-one translations.

## Examples to prototype
- English: "What goes with rice?"
- Tagalog: "Ano ang bagay sa kanin?"
- Taglish: "Ano ang bagay with rice?"
- English: "Lola Override: Eat already."
- Taglish: "Lola Override: kain na. Stop overthinking it."

Examples are provisional, not native-speaker verified. Preserve WikaTayo's existing native-speaker-review requirement and other language cautions. Filipino food and multilingual speakers are not the joke; academic overengineering is.

## Collaborator tasks
1. Review all Tagalog/Taglish strings with speakers; mark verified versus provisional.
2. Propose a lightweight reusable language toggle that works in offline single-file HTML exhibits.
3. Preserve original phrasing, translation notes, and speaker feedback separately.
4. Coordinate the Ulam toy and research versions without forcing a literal translation across registers.

Do not move private autobiographical notes or Q residue here. No live site is implied.
